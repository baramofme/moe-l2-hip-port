## 观察结论

1. **SM120a 验证通过**：多架构包在 RTX 5090（Blackwell）上 DS + Qwen 全部正常加载/推理（8 组场景全过）
2. **⚠️ 50 系内核效率待提升**：5090 未碾压 3080 Ti（DS +36%，Qwen -27%）。llama.cpp 76f46ad 对 Blackwell（sm_120a，FP4 优化架构）的 FP16 内核优化不成熟；换新版 llama.cpp 重编多架构包后 50 系速度有望提升
3. **显存占用与架构无关**：DS 1.0-1.8 GB、Qwen 2.1-2.5 GB，各代卡一致（host-buffer 特性），8 GB 卡可行性余量 3-6 倍
4. **gen 速度与对话场景无关**：每卡各场景差异 <10%（生成每 token 算力相同，上下文只影响 prefill 与 KV 显存）
5. 长 prompt prefill 快：5090 上 DS 555 / Qwen 334 t/s（批量 prefill 效率高）

## Qwen / DS-V2 同卡对照：裸 server vs v3.1 全链路（2026-08-05 补充）

**⚠️ 对比口径警示**：multi-arch 主表里 3080 Ti 的数据（Qwen 13.28 / DS 12.25 t/s）来自 **3080 Ti 12GB**（10240 cores）且是**裸 llama-server** 口径；本机 v3.1 全链路测在 **RTX 3080 10GB**（8704 cores，算力低 ~17%，显存带宽 760 vs 912 GB/s）——**跨卡直接比会把"卡差异"误读成"淘汰掉速"**。要看淘汰机制是否掉速，必须同卡比裸 vs 全链路。

**RTX 3080 10GB（region-41，SM86）同卡实测**，口径：128 token、n_predict=128、c=2048、`MOE_L2_EVICT_MB=3000 INTERVAL=4 LRU=1 MAX_EXPERTS=4000`、L2 4GB、热身后取值：

| 模型 | 裸 server（无淘汰） | v3.1 全链路 | 淘汰影响 | server RSS（全链路） | VRAM |
|------|---------------------|-------------|----------|---------------------|------|
| Qwen3.6-35B-A3B | 8.77 t/s | 9.40-9.41 t/s | **+7%** | 4.5GB | 2.3GB |
| DS-V2-Lite | 8.66 t/s | 10.21-10.23 t/s | **+18%** | 5.6GB | 3.3GB |

**结论**：
1. **v3.1 淘汰机制不掉速**——同卡对比全链路反而更快（L2 热专家预加载 + gate 领域预测收益 > 淘汰开销），Qwen +7%、DS +18%
2. 与主表 3080 Ti 的差距（Qwen -29% / DS -17%）是**卡差异**（3080 Ti 10240 cores vs 3080 8704 cores + 带宽差），不是淘汰机制代价
3. Qwen 全链路 9.4 t/s 与 2080 Ti 原测全链路 9.26-9.40 t/s 持平（两卡对 Qwen 都够快，瓶颈在专家搬运）
